# Keystone

**Category:** REV  
**Difficulty:** Easy  
**Points:** 100

Somebody's selling "cracked" builds of a tool that still checks for a license.

We got our hands on the binary. Find out what it's hiding.

### Files

Download the `keystone` binary and investigate it.

### Objective

Get the program to print the flag.

> Hint: `strings` won't get you far. Look at how the input is compared.
