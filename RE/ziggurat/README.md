# Ziggurat

**Category:** REV
**Difficulty:** Insane
**Points:** 600

They dug it out of the same archive as the obelisk. Same builder, more paranoid.

The last team that cracked the obelisk grabbed a single constant and walked off with the flag. This one doesn't leave a constant lying around. Nothing here decrypts until you make it run.

### Files

Download the `ziggurat` binary.

### Objective

Say the correct rite and it prints the flag.

> Hint: the disassembly of the interpreter is not the program. The program is data, and the data is asleep until it's fetched.
