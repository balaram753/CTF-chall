# Echoes

**Category:** PWN  
**Difficulty:** Easy  
**Points:** 100

The Echoes terminal was built to repeat whatever users type.

The developer was confident that nobody would type *too much*.

Can you make the terminal reveal something it was never supposed to?

### Connection

```text
nc <HOST> <PORT>
```

### Files

Download the `echoes` binary and investigate it.

### Objective

Get the program to reveal the flag.

> Hint: The program trusts your input more than it should.
